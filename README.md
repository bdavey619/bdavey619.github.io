# bdavey619.github.io

Personal website. Plain HTML, CSS, and vanilla JS. Hosted on GitHub Pages.

## Local development

Open `index.html` in a browser, or serve locally:

```
python3 -m http.server 8000
```

## Structure

- `index.html` — Home
- `projects/` — Project pages
- `writing/` — Blog posts
- `quotes.html` — Quotes collection
- `css/style.css` — Design system
- `js/main.js` — Dark mode, quote filtering
